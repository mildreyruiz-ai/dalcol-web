# Dal Col 1924 · sitio web (borrador)

Sitio de una sola página para **Dal Col 1924**, pane e pasticceria en Via Angarano 33, Bassano del Grappa. Mensaje central: la tradición de un nombre con un siglo de historia.

- HTML y CSS en un solo `index.html`, sin dependencias ni build. Tipografías desde Google Fonts.
- Fotos en `images/`, tomadas del Instagram @dalcol1924 con autorización del cliente. El póster del hero se recreó con Higgsfield (GPT Image 2.5) a partir del diseño de la longsleeve.
- Pendiente del cliente: historia de 1924, horarios confirmados, teléfono, lista de pan y dulces con precios y alérgenos, link del shop, logo vectorial.

## Publicar para revisión
Arrastra esta carpeta completa (con `index.html` e `images/`) a un proyecto de Cloudflare Pages (Direct Upload).
